# Minecraft Circle & Curve Calculator

A single-file web app for planning circles, arcs and S-curves in Minecraft. It
runs entirely in the browser, with no dependencies, no build step and no
backend, so it can be hosted as-is on GitHub Pages.

## Features

### Circle
- Enter the size as a **diameter** or a **radius**.
  - Radius accepts half-blocks (for example `10.5`).
  - Optional "count radius from the center block" mode (diameter = 2r + 1).
- Choose a **thin** or **thick** outline.
- Set the **line thickness** in layers (1–20).
- Shows the total outline blocks and the filled-disc block count, both converted to stacks of 64.

### Arc
- Uses the same circle as the Circle tab, so arcs always line up with full circles.
- Set a **start angle** and a **sweep angle** (0° points up, clockwise).
- One-click presets for quarter and half circles.
- Optional faint full circle as a reference.

### S-curve
- A straight path that needs to shift sideways, built from two mirrored arcs.
- Define it by either:
  - **L + S**: forward distance and sideways offset, or
  - **R + S**: arc radius and sideways offset.
- Optional straight sections before and after the curve.
- Vertical or horizontal, and shift left, right, up or down.
- Shows the calculated radius and angle of each arc.

### Output
- Interactive grid with row/column rulers and a hover read-out (for circles, offsets from the center are shown in X/Z).
- **Row-by-row build guide** in a "skip → place" format with a block count per row.
- **Download PNG** of the grid.
- **Copy as text** (`■` for a block, `·` for empty) to paste into notes.

## Usage

1. Pick a tab: **Circle**, **Arc** or **S-curve**.
2. Enter your dimensions. Results update live.
3. Choose **Thin** or **Thick**, and set the number of layers.
4. Build from the grid or the row-by-row table.

### Thin vs thick

| Style | Rule | Result |
|-------|------|--------|
| Thin  | A block is on the outline if any of its 4 side neighbours is outside the shape | Fewer blocks; neighbouring blocks may touch only at corners (diagonal) |
| Thick | A block is on the outline if any of its 8 neighbours is outside the shape | Blocks always share a full side; no diagonal-only joins (good for walls and watertight edges) |

### Reading the build guide

Each row shows the pattern counted from the left edge of the displayed frame.
For example, `skip 4 → place 3 → skip 2 → place 3` means: leave 4 blocks empty,
place 3, leave 2 empty, place 3.

For full circles, only the top half is listed because the shape is symmetric.
Mirror it for the bottom half.

## How it works

### Circle and outline

A block `(i, j)` is inside a circle of diameter `D` when its center is no
farther than `D / 2` from the circle's center:

```
(i + 0.5 − D/2)² + (j + 0.5 − D/2)² ≤ (D/2)²
```

The outline is made by repeatedly peeling the outermost layer off this filled
shape. The number of peels is the line thickness. The 4-neighbour or
8-neighbour test decides whether the result is thin or thick.

### Arc

The full circle outline is computed first, then filtered by angle:

```
angle = atan2(dx, −dy)   // 0° = up, clockwise
```

Because the arc is cut from the same outline, it joins perfectly with a full
circle of the same size.

### S-curve

An S-curve is two arcs of equal radius `R` bending in opposite directions. Each
arc turns by the angle `θ`, and the path ends up shifted sideways by `S` over a
forward distance `L`.

With forward distance `L` and offset `S`:

```
R = (L² + S²) / (4S)
θ = 2 · atan(S / L)
```

With radius `R` and offset `S`:

```
θ = acos(1 − S / (2R))
L = 2R · sin(θ)
```

The path is generated by treating the area on one side of the curve as a shape
and peeling its edge, so thin/thick and multi-layer thickness behave the same
way as for circles.

**Constraints:** `S ≤ L` (or `S ≤ 2R`). A larger offset would make the path double back on itself.

## Deploying to GitHub Pages

1. Create a new repository and add `index.html` to the root.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then select `main` and `/ (root)`, and click **Save**.
4. After a minute or two the site is live at `https://<username>.github.io/<repository>/`.

To run locally, open `index.html` in any modern browser. No server is needed.

## Limits

| Setting | Range |
|---------|-------|
| Diameter | 1–300 blocks |
| Line thickness | 1–20 layers |
| S-curve offset (S) | 1–200 blocks |
| S-curve total length | up to 800 blocks |

## Browser support

Any modern browser with HTML5 canvas support (Chrome, Edge, Firefox, Safari).

`localhost`. GitHub Pages serves over HTTPS, so it works there.
